# Breeze Plugin Docs

插件开发文档 / Plugin development docs (Docusaurus).

- 中文：站点根路径 `/`
- English: `/en/`

## 开发 / Development

```bash
pnpm install
pnpm dev
```

## 构建 / Build

```bash
pnpm build
pnpm serve
```

## 目录 / Layout

- 中文文档：`docs/`
- English docs: `i18n/en/docusaurus-plugin-content-docs/current/`
- Docusaurus 配置：`docusaurus.config.js`、`sidebars.js`
